# Version 0.22 – June 3, 2025

## 🚀 Summary

- Major improvements to Bao Dưỡng and Định Mức Chở Hàng modules
- Enhanced flexibility, usability, and UI consistency
- Improved data management and navigation

## ✨ New Features

### 🔧 Bao Dưỡng Module

- Added support for multiple item types beyond just **Lốp Xe**
- Implemented serial number (STT) column in all tables
- Introduced pagination for better data navigation
- Added license plate (Biển Số) filter
- Integrated search bar (50% width) with license plate dropdown
- Optimized `BaoDuongDialog` for all screen sizes

### 📊 Định Mức Chở Hàng Module

- Applied consistent design from Bao Dưỡng module
- Added paginated tables with STT
- Enhanced filtering capabilities

### 🛠️ Components

- Enhanced `StandardTable` with default STT column
- Improved sort functionality for row numbers

## 🎯 Impact

- Streamlined data management workflows
- Consistent user experience across modules
- Better performance with pagination
- Improved mobile responsiveness
