# Phiên bản 0.13

## 1. Trang Lịch Vận Chuyển

- Thiết kế lại giao diện theo mẫu trang Quản lý nhân viên
- Di chuyển thanh tìm kiếm lên trên bảng dữ liệu
- Thay nút thêm mới thành nút nổi ở góc phải dưới màn hình
- Tách code thành hai phần riêng biệt cho giao diện điện thoại và máy tính
- (Mobile & Desktop) Khi tạo kế hoạch vận chuyển mới, quản lý chọn loại đầu kéo, web sẽ tự điền mã nhân viên và tên lái xe.

## 2. Trang Quản Lý Nhân Viên

- Thêm trường mã nhân viên (ví dụ: NV001)
  - Hệ thống tự điền mã nhân viên khi thêm mới
  - Quản lý có thể thay đổi mã nếu cần
- Cải thiện xác nhận xóa:
  - Thay thế system dialog bằng modal xác nhận đẹp hơn
- Thêm tính năng quản lý xe:
  - Thêm chức năng gán xe kéo cho nhân viên lái xe
  - Quản lý có thể chọn biển số xe khi thêm hoặc sửa thông tin nhân viên lái xe

## Trang Quản Lý Khách Hàng

- Thêm trường mã khách hàng (ví dụ: KH001)
  - Hệ thống tự điền mã khi thêm mới
  - Quản lý có thể thay đổi mã nếu cần

## Trang Quản Lý Đối tác

- Thêm trường mã đối tác (ví dụ: DT001)
  - Hệ thống tự điền mã khi thêm mới
  - Quản lý có thể thay đổi mã nếu cần
