# Version 0.23 – June 7, 2025

## 🚀 Overview
Standardized UI components, enhanced logging infrastructure, and database schema improvements for better maintainability and user experience.

## ✨ New Features

### 🚗 Vehicle Management
- Consistent search and pagination implemented for:
  - `/phuong-tien/container`
  - `/phuong-tien/dau-keo`
  - `/phuong-tien/ro-mooc`

### 🛠️ Technical Enhancements
- **Centralized Logging Service**
  - **Log Levels**:
    - `info`: Application flow and status updates
    - `warn`: Non-critical issues requiring attention
    - `error`: Critical errors affecting functionality
  - **Environment-Specific Behavior**:
    - Development: All log levels (info, warn, error)
    - Production: Error logs only
  - **Benefits**:
    - Reduced noise in production
    - Context-aware structured logging
    - Seamless migration from console.* methods
- Refactored search and pagination components for reusability
- Aligned UI patterns with QuanLyKhachHang standards
- Optimized data fetching and state management

## 📊 Database Updates
- **DinhMucDiDuong Table**:
  - Removed column: `Ten Tuyen`
  - Added columns: `Diem Di`, `Diem Den`
  - Removed `tuyenDuong` data model

## 🎯 Impact
- **Improved Usability**: Consistent interface across vehicle management modules
- **Enhanced Performance**: Optimized data handling and state management
- **Better Maintainability**: Standardized logging and component patterns
- **Cleaner Production**: Reduced log noise while maintaining debugging capabilities

## Page DinhMucDiDuong
- Added FAB for new record creation
- Added "Thao Tac" column with Edit/Delete actions
- Inline editing with save/cancel functionality
- Delete confirmation modal
- New row addition with empty fields and STT = ''

## Page DinhMucBoSung

### Data Model
```javascript
{
  id: 1,
  bien_so: '15C-11.222', // References dauKeo.bien_so (null = applies to all)
  ma_tuyen: '123',        // References tuyenDuong.ma_so (null = applies to all)
  dinh_muc_l: 100.0,     // Liters
  createdAt: '2023-01-01T08:00:00Z',
  updatedAt: '2023-01-01T08:00:00Z'
}
```

### Implementation Details
- Display "*" for null `bien_so` or `ma_tuyen`
- Table configured with `showSTT` and `showAction` set to true
- Tooltip added to explain "*" (applies to all)
- FAB for new record creation

### Add/Edit Functionality
- **Add/Edit Form (AddEditDinhMucBoSung.jsx)**:
  - Create/edit tuyen duong (diem di, diem den)
  - Select bien so dau keo (dropdown)
  - Input dinh muc l
  - "Tat Ca" option for existing tuyen duong
  - Separate button to add/edit tuyen duong (opens modal)
