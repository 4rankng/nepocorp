### 🛠️ Technical Improvements
- **Centralized Logging Service**
  - **Three Log Levels**:
    - `info`: General application flow and status updates
    - `warn`: Non-critical issues requiring attention
    - `error`: Critical errors affecting functionality
  - **Environment-Aware**:
    - Development: Shows all log levels (info, warn, error)
    - Production: Shows only error logs
  - **Key Benefits**:
    - Cleaner production console
    - Structured logging with context support
    - Easy migration from console.* methods
- Refactored search and pagination logic for better reusability
- Aligned UI patterns with QuanLyKhachHang component standards
- Optimized data fetching and state management
