[x] **Sửa lỗi**

- Sửa lỗi bảng trong /lich-van-chuyen không thể tải dữ liệu
- Cải thiện xử lý lỗi khi tải dữ liệu từ API
- Sửa lỗi hiển thị mã chuyến xe trong danh sách lịch vận chuyển

[x] **Cải thiện quản lý trạng thái**

- Triển khai các custom hooks để tương tác dữ liệu trong các module:
  - usePartnerManagement cho quản lý đối tác
  - useNhanVienManagement cho quản lý nhân viên
  - Hỗ trợ caching dữ liệu và retry logic khi API gặp lỗi

[x] **Nâng cao xử lý lỗi**

- Thêm ErrorBoundary cho tất cả các routes chính
- Triển khai ErrorFallback component để hiển thị lỗi thân thiện với người dùng
- Tích hợp react-error-boundary để cải thiện trải nghiệm người dùng khi xảy ra lỗi

[x] **Cải thiện cấu trúc dữ liệu**

- Cập nhật mô hình dữ liệu lịch vận chuyển với các trường mới
- Đảm bảo tính toàn vẹn dữ liệu giữa các bảng liên quan
- Tối ưu hóa logic tính toán chi phí vận chuyển

[x] **Tối ưu hóa hiệu suất**

- Loại bỏ các dependencies TypeScript không cần thiết
- Cải thiện cơ chế caching dữ liệu
- Tối ưu hóa cách xử lý dữ liệu lớn
