# Changelog - v0.15

## ✨ Features & Enhancements

- **Đối tác (Partners):**
  - The "Mã đối tác" (Partner Code) field is now automatically filled with the next available code when adding a new partner, streamlining data entry.
- **Khách hàng (Customers):**
  - Improved the layout of the "Add/Edit Customer" form: "Mã khách hàng" (Customer Code) and "Mã số thuế" (Tax Code) fields are now displayed on the same row for a more compact view.
  - Standardized the height of input fields in the customer form for a consistent look and feel.
- **Nhân viên (Employees):**
  - Enhanced the vehicle selection dropdown for drivers by ensuring unique internal IDs for tractors (đầu kéo) and trailers (rơ moóc), improving system stability.

## 🐞 Bug Fixes

- **Đối tác (Partners):**
  - Fixed an issue in the partner deletion confirmation dialog where the partner's name, address, and tax code were not displaying correctly.
- **Nhân viên (Employees):**
  - Resolved a console warning ("two children with the same key") that could occur when selecting a vehicle in the employee form.
- **General UI:**
  - Addressed a DOM nesting warning in the general confirmation dialog component to ensure valid HTML structure.

## ⚙️ Refactoring & Chores

- Minor updates to the underlying logic for customer and employee management to support the recent UI improvements and bug fixes.
