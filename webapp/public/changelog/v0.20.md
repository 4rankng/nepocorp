# Phiên bản 0.20

## 🔧 Chuẩn hóa API Response Format

### 📊 Định nghĩa Standard Response Format

Để hỗ trợ pagination và theo best practices của industry, tất cả API endpoints sẽ trả về format chuẩn như sau:

#### Response Format cho List APIs

```
interface ApiResponse<T> {
  data: T[];                    // Mảng dữ liệu chính
  meta: {
    count: number;              // Số records trong response hiện tại
    offset: number;             // Vị trí bắt đầu (0-based indexing)
    limit: number;              // Số records tối đa mỗi trang
    page: number;               // Trang hiện tại (1-based)
    totalPages: number;         // Tổng số trang
  };
  message?: string;             // Thông báo (optional)
  success: boolean;             // Status thành công
}
```

#### Response Format cho Single Record APIs

```
interface ApiSingleResponse<T> {
  data: T;                      // Object dữ liệu
  message?: string;             // Thông báo (optional)
  success: boolean;             // Status thành công
}
```

#### Error Response Format

```
interface ApiErrorResponse {
  error: {
    code: string;               // Mã lỗi
    message: string;            // Thông báo lỗi
    details?: any;              // Chi tiết lỗi (optional)
  };
  success: false;               // Luôn là false cho error
  timestamp: string;            // Thời gian xảy ra lỗi (ISO format)
}
```

## ✨ Cải Tiến Giao Diện Người Dùng (UI Enhancements)

### 🚛 Quản Lý Phương Tiện

- **Triển khai Floating Action Button (FAB) nhất quán**:
  - Áp dụng nút "Thêm" dưới dạng FAB (fixed, bottom-right) cho các tab "Đầu Kéo", "Rơ Mooc", và "Container".
  - Đảm bảo FAB luôn hiển thị, giúp người dùng dễ dàng thực hiện thao tác thêm mới.
  - Điều chỉnh padding của vùng nội dung để FAB không che khuất các mục cuối danh sách.
  - Chuẩn hóa kích thước (56x56px) và kiểu dáng (bo tròn, hiệu ứng hover, đổ bóng) của FAB cho đồng bộ với các khu vực khác trong ứng dụng (ví dụ: `/doi-tac`).
