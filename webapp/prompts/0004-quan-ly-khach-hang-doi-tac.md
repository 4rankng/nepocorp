# Đối với quản lý khi xem trang Khách hàng và Đối tác

Thông tin của khách hàng bao gồm:

- Mã (ví dụ: CDMC)
- Tên (ví dụ: Công ty Cổ phần Chè)
- Địa chỉ (ví dụ: 123 Đường Lê Lợi, Quận 1, TP. Hồ Chí Minh)
- Mã số thuế (ví dụ: 5500157123)

Thông tin của đối tác bao gồm:

- Mã (ví dụ: CDMC)
- Tên (ví dụ: Công ty Cổ phần Chè)
- Địa chỉ (ví dụ: 123 Đường Lê Lợi, Quận 1, TP. Hồ Chí Minh)
- Mã số thuế (ví dụ: 5500157123)

Yêu cầu thêm

- When a component want to use Icon button for Add / Edit / Delete, the component will use the same path to the icon eg assets/icons
  - Add is PlusIcon
  - Edit is PencilIcon
  - Delete is TrashIcon
- Dont use text for Add button, the placement of add button will give user the meaning of the button
- Remove material UI across codebase, we use Tailwind CSS only
