## Out-of-scope finding (NOT filed as bug — gap, not regression)

The forwarder route file (`backend/src/routes/forwarder.ts`) exposes only `POST /expenses` and `DELETE /expenses/:id`. **There is NO `PUT /expenses/:id`** for the forwarder to edit a sell price on an existing fee. The test guide's Scenario 1 / Bước 3 wording ("Khi Giao nhận đăng nhập cổng thông tin và sửa đổi Giá bán ra…") implies an edit path that flips status → PENDING; today the only way to land PENDING is via forwarder-CREATE.

This was also conflated in prior `service-cost-checklist.md F1.5` ("sell-side edit lands PENDING — confirmed for forwarder-created"). Recommend a separate ticket: add forwarder PUT endpoint with auto-PENDING semantics, OR adjust guide wording to "Giao nhận tạo phí mới → Chờ duyệt".
