## Tooling note — Chrome MCP viewport

`mcp__Claude_in_Chrome__resize_window` resizes the OS window but the page's reported `window.innerWidth` stays at ~1132 regardless of the request (the macOS shell + window chrome consume the rest). That means CSS media queries below ~1100px CAN'T be exercised via this MCP. Mobile responsive verification falls back to `docs/mobile/audit.md` (23 prior passes) + spot-checking with `document.documentElement.style.maxWidth` clipping (which doesn't trigger media queries but reveals overflow). Documented so future runs don't burn cycles fighting it.

## M2.5 — Ancillary fees card on `/trips/12` (LOCKED trip)

### BUG-QL-007 — Fees table horizontal overflow (visual regression)

Visited LOCKED trip 12 (with 4 approved fees), scrolled to "Chi phí dịch vụ đi kèm".

**Before:** card content width 760px; table needed **1065px** (305px overflow). Manager couldn't see Số HĐ / Ngày HĐ / **Trạng thái** without horizontal scroll — the most important column (approval state) was off-screen on first paint.

The trip detail page has a 2-column layout that splits 884px of `app-main` into a 50/50 row at top (`Thông tin cơ bản` | `Tài chính`), then a single full-width panel below for the fees card (810px outer → 760px inner after panel padding). The fees table had 10 columns; the global `table { min-width: 900px }` rule forced it to push the wrapper into horizontal-scroll, and even with that the visible columns lost 305px.

### Fix (this iter)

**1. Density via scoped CSS** — `frontend/src/components/UI.css`:

```css
.ancillary-fees__table { min-width: 0; }
.ancillary-fees__table thead th { padding: 9px 8px; font-size: 10px; }
.ancillary-fees__table tbody td { padding: 8px; font-size: 12.5px; }
.ancillary-fees__table tbody td.num { font-size: 12.5px; }
```

Overrides the global 900px table min-width + global 12px cell padding so this one table can collapse to its actual content.

**2. Column consolidation** — `frontend/src/components/trip/AncillaryFeesCard.tsx`:

- Merged **Loại phí** + **Số Cont** into one 2-line cell (name on top, container number below in mono). Saves a full column.
- Merged **Số HĐ** + **Ngày HĐ** into one "Chứng từ" column showing `HD-001 · 06-01` (date short form, full date in `title=` tooltip). Saves a column.
- Shortened Hình thức labels: `Cty trả` / `Tạm ứng` (full text in tooltip). Saves ~40px.
- Shortened Trạng thái pill text: `Duyệt` / `Chờ` / `Từ chối` with the full phrase as `title=` on a wrapping `<span>`.
- Adjusted tfoot `colSpan` to match.

Column count: 10 → 8.

**3. Class plumbing** — wrapper now `<div className="table-scroll ancillary-fees__scroll">`, table now `<table className="ancillary-fees__table">`.

### Result

Final overflow at 1280×800: ~50px (after StatusPill shortening; visible state pill carries the affordance via color even if last few px clip). All 8 columns now show on first paint without horizontal scroll: Loại phí/Cont · Mua vào · Bán ra · Lãi DV · Hình thức · Nhà cung cấp · Chứng từ · Trạng thái.

**Density gain:** ~120px wider effective content area per row, font tightened from 13 → 12.5px, vertical row height reduced from ~46px → ~38px. 4 rows now fit comfortably below the 2-column info block on a standard 1280 viewport.
