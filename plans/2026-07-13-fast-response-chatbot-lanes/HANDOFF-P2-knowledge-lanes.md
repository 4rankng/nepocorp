### Files created/modified (10)

### How it works

```
User: "Tiền chuẩn là gì?"
   │
   ▼
Orchestrator (ReAct loop) → calls knowledge.search("tiền chuẩn")
   │
   ▼
retrieveKnowledge:
   ├─ embed query (Redis cached)
   ├─ pgvector cosine over knowledge_chunks
   └─ top-5 chunks ≥ 0.30 similarity
   │
   ▼
Orchestrator synthesizes answer from chunks
   └─ attaches citations: [{sourceId, label: "Tiền chuẩn", kind: "doc"}]
   │
   ▼
Frontend renders answer + 📄 citation chips
```
