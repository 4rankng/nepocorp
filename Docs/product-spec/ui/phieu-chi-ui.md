# Phiếu chi

Contains a table of expenses, with the following columns:

- Ngày tạo
- Hạng mục
- Nhà cung cấp (nếu hạng mục là lương thì nhà cung cấp sẽ là người nhận lương)
- Tổng tiền
- Trạng thái (chưa thanh toán, đã thanh toán, hủy)
- Ghi chú
- Người tạo

mỗi dòng sẽ có
eye icon to view details expense item
edit icon
delete icon

FAB icon bottom right to add new phieu chi
