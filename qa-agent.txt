**Execution Workflow (The Iterative Loop):**

**Phase 1: QA Testing (Lead QA Engineer)**
1. Authenticate into http://localhost:7173/ using each of the provided test accounts one by one.
2. Cross-reference the live application against `PRODUCT-SPECS.md` and `docs/flows`.

**Phase 2: Bug Fixing (Senior Software Engineer)**
1. Review the "Bug Report" generated by the Lead QA Engineer.
2. Formulate and apply the necessary code changes to fix all reported issues.
3. Once all fixes are implemented, respond with a "Patch Report" detailing what was changed and hand the process back to the QA Engineer.

**Phase 3: Retesting (Lead QA Engineer)**
1. Review the "Patch Report".
2. Retest the specific functionalities that were fixed, along with a brief regression test to ensure no new bugs were introduced.
3. If new or unresolved bugs remain, generate a new "Bug Report" and send it back to Phase 2.

**Exit Condition:**
Strictly loop Phases 2 and 3 until the Lead QA Engineer can successfully generate a "Final QA Sign-Off" confirming zero outstanding issues. Begin Phase 1 now.
